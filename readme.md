## 🛠️ What I Build

**📱 Iranian Bank Transaction Verifier — Android App**
Kotlin + Jetpack Compose + Room + Retrofit app that parses Persian bank SMS and transfer receipts, auto-matches transactions, tracks Toman/Rial balances, and pushes real-time alerts through a Telegram bot integration. Supports Jalali date formatting, full Persian UI strings, and VPN/proxy-aware connectivity handling.

**🤖 Telegram Bot Automation Suite**
A set of production bots spanning web scraping and **Divar-to-Telegram ad forwarding**, plus a new line of AI chat assistants — deployed in parallel across **Telegram, Rubika, and Bale** on TeleBotHost and wired to the Claude API for conversational features. Includes [`hydra-sender`](https://github.com/aliaslany/hydra-sender), a messaging/notification dispatcher.
